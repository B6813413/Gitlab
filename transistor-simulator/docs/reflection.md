## 2. HTTP request/response

ที่ browser ส่ง (`POST /`), การที่ Flask เข้า route `index()`, และ response ที่กลับไป

- ทำไมการดับเบิลคลิกเปิด `templates/index.html` (`file://`) จึงไม่เท่ากับรัน Flask?
- ค่าฟอร์มเดินทางจาก HTML มาถึง Python อย่างไร?
